# Changelog

## 0.1.1

- Vision category `stain` for a mark with no standing liquid
- `water` in the example prompt is standing liquid only
- Lifted, buckled, or sagging flooring is damage

## 0.1.0

First release of the thin framework. Not published to PyPI.

- Rule registry, YAML loader, and three sample rules (active water, freeze, outage)
- Sample thresholds, separate from any host package's own file
- Severity model and delivery policy
- Vision contract, parser, pixel gate, and a generic example compare prompt
- Inspection-language linter and consequence ranking
- Psychrometrics, display units, and regional storm names
- Appliance expected-life table and sample serial-decoding rules
- Synthetic sensor fixtures
